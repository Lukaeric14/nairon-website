## PLAUSIBILITY CHECK (mandatory, added 2026-07-13 after the aerial-rooftops failure)

Before submitting any prompt, and again before delivering any result, answer: **would a real photographer's shot of this scene look like this?** Concrete checks:

- **Adoption logic:** solar arrays on 1–2 houses per street, not all; one heat pump per wall, not rows on a home; commercial uniformity (battery yards, warehouse arrays, apartment rooftop units) is the only place repetition is real.
- **Variety logic:** neighboring buildings differ in shape, age, color, roof pitch, orientation. Streets have cars, wear, mature trees. Write the variety into the prompt — models default to cloned buildings.
- **Repetition rule:** repeating-pattern compositions only on manufactured installations (a single large array, a battery yard, a mechanical rooftop) — never on organic scenes like neighborhoods.
- **Hardware logic:** units have the parts they have in reality (fan grilles, conduit, disconnects); nothing floats, nothing is duplicated where one would exist.

A result that fails any check is not delivered — fix the prompt, re-roll. Failure that triggered this rule: n01-aerial-rooftops (every house paneled, near-identical houses), rejected by Luka.

**Standing negative additions for scene shots:** "identical cloned houses, copy-paste buildings, every roof with solar panels, unrealistically uniform neighborhood."

## Prompt formula

`[SUBJECT — one sentence, specific] + [FROZEN BLOCK] + [SHOT NOTE — focal length / angle / movement if video]` with the standing negative prompt in the model's negative field (or appended as "Avoid: …" where no field exists).

Rules (from PROCESS.md, restated):
- One variable changes per re-roll.
- Same model + model version within a sequence; regenerate the anchor shot and compare when resuming after days.
- Five failed generations on one shot → change the prompt, the model, or the shot.
- Every generation logged in `video/LEDGER.md`: prompt, model, references, seed, verdict.
