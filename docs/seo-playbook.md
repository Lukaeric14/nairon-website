# SEO Playbook — naironai.com

How the site's SEO machinery works and how to ship content that ranks. The
system is programmatic: content lives in data files, and every SEO surface
(sitemap, llms.txt, JSON-LD schema, page listings) is generated from them.
You should almost never hand-edit an SEO artifact.

## The machinery

| Surface | Source of truth | Generated by |
|---|---|---|
| `sitemap.xml` | verticals + roles + signals registries | `apps/web/scripts/generate-sitemap.ts` (runs on every build) |
| `llms.txt` (AI answer engines) | same registries | same script |
| Canonical/OG/Twitter meta | `seoHead()` in `apps/web/src/lib/seo.ts` | each route's `head()` |
| Article schema (BlogPosting + breadcrumbs) | `articleHead()` in `lib/seo.ts` | article route's `head()` |
| Vertical schema (Service + Breadcrumb + FAQPage) | `content/verticals.ts` + `content/vertical-faqs.ts` | `industries.$slug.tsx` / `solutions.$slug.tsx` |
| robots.txt AI-crawler allowlist | `apps/web/public/robots.txt` | hand-maintained (rarely changes) |

Host canonicalization: apex `naironai.com` is primary; `www` 308-redirects to
it (configured at the Vercel domain level, NOT in vercel.json — an app-level
host redirect there will loop).

## Ship a Signals article that ranks

1. **Create the route** at `apps/web/src/routes/signals/<slug>.tsx`.
   - `head: () => articleHead(article)` — that one call emits canonical, OG
     (article type), Twitter card, BlogPosting schema, and breadcrumbs.
   - Exactly one `<h1>` (the title); sections as `<h2>`/`<h3>`, no level skips.
   - Real `<a>`/`<Link>` internal links to at least 2 related pages
     (verticals, other articles) — internal links are how new pages get
     crawled fast and how authority flows.
2. **Register it** in `apps/web/src/content/signals.ts` (slug, title,
   description, ISO date, author). This alone puts it in the sitemap,
   llms.txt, and the Signals index.
3. **Title/description rules**: title ≤ 60 chars with the target phrase near
   the front; description 140–160 chars, written like an answer (AI engines
   quote these nearly verbatim).
4. **On meaningful updates**, set `dateModified` in the registry — freshness
   is a ranking input and the sitemap `lastmod` flows from it.

What makes an article actually rank (the part no machinery can do): pick one
specific question a buyer types, answer it in the first 150 words, then go
deeper than anyone else on page one. Comparison tables, real numbers from
production, and named tools (like the agent-memory piece) are what earn links
and LLM citations.

## Add a new industry/solution page

Add one entry to `ENTRIES` in `apps/web/src/content/verticals.ts` (+ its tools
in `TOOLS`). Everything else is automatic: route, unique meta, Service +
Breadcrumb + FAQPage schema, generated FAQ section, sitemap, llms.txt.

## Verify after deploy

- `curl -s https://naironai.com/sitemap.xml | grep <new-path>`
- Rich results test: https://search.google.com/test/rich-results
- Google Search Console → submit the URL for indexing (fastest discovery).
