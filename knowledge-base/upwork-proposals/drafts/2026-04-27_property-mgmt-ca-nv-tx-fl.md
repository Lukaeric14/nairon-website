## Job post

22-year-old commercial property management firm (11 employees, 112 clients across CA/NV/TX/FL) rebuilding ops with AI automation. Wants a builder, not a strategy or advisory hire. Scope:

- Build AI automations against pre-documented SOPs and workflows
- Integrate Claude / Cowork with existing tools (Microsoft 365, Appfolio, Laserfiche)
- Debug, maintain, and iterate on deployed automations
- Write clear technical documentation so workflows can be operated by non-technical staff
- Monitor new AI tools and surface ones worth evaluation

Required: 12 months hands-on with LLMs in production, demonstrated track record of shipped automations with measurable outcomes (must provide examples), API integration experience, strong written communication.

Engagement: Hourly $35–$100, 15–20 hrs/week, 3-month initial (extendable based on performance), remote / async-friendly / Pacific Time preferred.

**Hard proposal filter (won't review otherwise):**
1. Links or descriptions of 2–3 automations you've built, including the business outcome each produced
2. One sentence on what you think is overrated in the current AI space
3. One sentence on what you think is underrated
4. Any questions about scope (encouraged)

## Proposal sent

You said it clearly — you want a builder who can ship against documented SOPs, not an advisor. That's the mode I default to.

Direct answers to your requirements:

1. Two automations I've shipped with measurable business outcomes:
   • At CodeGPT (technical advisor), I designed the customer-success automation stack that lets a 3-person team support a 1M-user base. SOP-driven LLM triage and response with human escalation for edge cases.
   • For a real estate operator (Keylead), I built an AI-driven lead-qualification agent. Qualification time moved from agent-hours to seconds — the operator now treats it as core infrastructure, not a tool.

2. Overrated: multi-agent frameworks (CrewAI / AutoGen) for most production work. One well-instrumented agent with solid tool use and memory usually beats a swarm.

3. Underrated: observability and replay. You can't tune what you can't see. Every production agent I ship has full action logs and human approval gates on anything that writes.

Integrating Claude against documented SOPs + Microsoft 365, Appfolio, and Laserfiche is squarely my zone. I work from the SOPs as the agent spec, put approval gates on anything that writes, and ship in iterations so each automation is live and useful before we layer the next.

One question back: which of your SOPs is the most painful for the team today? That's usually where v1 should live.

15-min to talk through it: https://cal.com/naironai/discovery-call
